Minecraft, Fabric Loader, Fabric API and JNA are runtime/development dependencies;
they are not redistributed as separate libraries in the Mod JAR.
The standalone helper includes only the project's core classes and Gson.

The Mod JAR additionally embeds Netty HTTP Codec 4.1.82.Final as a Fabric nested JAR,
matching the Netty version provided by Minecraft 1.20.1.
